# 화장품 제조업 MES 목업

화장품 충전·포장 공장의 생산시점관리(POP)·설비 모니터링·자재·분석·검사기록 화면을 클릭해 볼 수 있는 단일 HTML 목업입니다. 서버나 설치 없이 `index.html`을 브라우저로 열면 됩니다.

- 언어: 한국어 / English / 日本語 (상단 언어 버튼)
- 테마: 다크 / 라이트 (상단 테마 버튼)
- 로그인: 아이디·비밀번호 아무 값이나 입력하면 들어갑니다. 주소 끝에 `#auto`를 붙이면 로그인 화면을 건너뜁니다. 로그인 화면에서 **현장 POP**를 고르면 설비 옆 모니터용 전체화면으로 바로 들어갑니다.
- 데이터: 모든 데이터는 예시이며 브라우저(localStorage)에만 저장됩니다. 브라우저 사이트 데이터를 지우면 처음 상태로 돌아갑니다.

## 화면 구성 (35종)

| 구분 | 화면 |
|---|---|
| 대시보드 | 홈, 실시간 공정 모니터링(공장·층별 경광등·설비 상세), 전체내역 모니터링(생산현황 상세 포함) |
| 공정관리 | 작업배정목록, 설비별 현황 모니터링, 설비별(품목별) 그래프 조회 |
| 생산시점관리 | 충·포장 실적입력(작업준비→시작→중단/재개→완료, LOT 실적, 불량 등록, 추가자재, POP 표기설정), 작업완료관리, POP |
| 자재관리 | 품목정보조회, 품목재고조회, 자재입고확인, 자재환입, 자재예약, 자재출고 |
| 데이터 수집·분석 | 생산성 조회(목표생산성 설정), 설비 종합효율(OEE), 충포장 실적, 수율, 가동률, 설비 비가동 분석(드릴다운·MTBF/MTTR), 노즐 시간겹침 간트 |
| 검사기록 | 충포장 기록서 작성·목록, 공정검사 기록서 작성(립스틱·리퀴드·파우더·마스카라·쿠션)·목록, 결재·출력 |
| 설비·시스템 관리 | 작업장 관리(센서·노즐), 사용자 관리, 권한 관리, 기록서 권한 관리, 접속 기록 조회 |
